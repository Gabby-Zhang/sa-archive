## 四、识别出的话术套路(可复用于以后判别)

1. **真锚点 + 假嫁接**:堆真实人名/地名/日期制造可信感。细节真 ≠ 事件真。
2. **「大家都知道」(tout le monde savait)**:免除举证责任的标志词。
3. **「不是 A,而是更严重的 B」**:用否认一个具体指控换信任,再塞更大指控。
4. **「多源趋同 = 印证」**:匿名私聊间无法核实,不构成新闻学意义的 corroboration。
5. **「媒体震耳欲聋的沉默」**:把「查无证据」反转成「真相被压」,阴谋论闭环。
6. **预先免责**:「记录的不是指控,而是信息流」——把编造包装成被动转述。
7. **法律概念偷换**:把 référé 程序结果夸大成「判例认证」。
