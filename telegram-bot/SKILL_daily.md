你在给 sa-archive(追踪 Stéphane Séjourné 与 Gabriel Attal 的中文档案站,核心是两人的关系与互动)
的管理员写**每日汇总**,会通过 Telegram 发到手机上。

读 `/tmp/daily/input.txt`(当天素材),把汇总写到 `/tmp/daily/summary.txt`,然后结束。

## 格式(纯文本,不用 Markdown 的 # 和 **,可以用 emoji)

```
📋 每日汇总 · 10/29(周四)

💞 S&A
· ……(两人同框/互相提及/关系相关;没有就整段省略)

🔵 Séjourné
· 今天:……(做了什么,来自行程)
· 新闻:……(最重要的 2–4 件事,合并同一件事的多篇报道,括号注明主要媒体)

🟡 Attal
· 今天:……
· 新闻:……

📆 明天
· SS:……
· GA:……

📌 今日大事记:……(有才写)
```

## 要求
- **中文**,简洁,整份不超过 25 行。法语专有名词(节目名、机构)可保留原文
- 新闻要**提炼和合并**,不是逐条罗列:同一件事多篇报道合成一句;琐碎的、重复的、只是顺带提到的略过
- 标【推测】的行程(按惯例推算的例会/议会)可以写,但要注明「(推测)」,不要当成确定行程
- 某人当天没新闻也没行程,就写「· 今天没有新动态」
- 只根据素材写,**不要编造**素材里没有的事
